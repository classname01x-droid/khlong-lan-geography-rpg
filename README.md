# Geography Mystery RPG: ปริศนาลับแห่งคลองลาน

เกมสืบสวนภูมิศาสตร์ 2D Pixel Art (Top-down) สำหรับนักเรียน ใช้พื้นที่ 4 ตำบลในอำเภอคลองลานเป็นฉาก
ผู้เล่นใช้ **ทิศทาง มาตราส่วน ระยะทาง และจุดสังเกต** เพื่อแก้ปริศนา และรวบรวมรหัสลับจากทั้ง 4 ตำบล

> สถานะ: **ต้นแบบ v0.1** — ด่าน 1 "ปริศนาลวดลายแห่งสักงาม" เล่นได้ถึงฉาก 2 (ระบบปริศนายังไม่ทำ)
> ภาพทั้งหมดเป็น placeholder ที่สร้างด้วยโค้ด

## เริ่มต้นใช้งาน

ต้องใช้ Node.js 22.12 ขึ้นไป

```bash
npm install
npm run dev        # เปิด http://localhost:5173
```

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `npm run dev` | รันเกมโหมดพัฒนา (แก้โค้ดแล้วรีโหลดอัตโนมัติ) |
| `npm test` | รัน unit test (มาตราส่วน ระยะทาง ทิศ หมอก และตรวจเนื้อหาด่าน) |
| `npm run typecheck` | ตรวจ TypeScript |
| `npm run build` | ตรวจ type แล้ว build ไปที่ `dist/` |
| `npm run preview` | เปิดไฟล์ที่ build แล้ว |

## การควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| `W A S D` / ปุ่มลูกศร | เดิน (เดินทแยงได้) |
| `E` / `Space` / `Enter` | คุยกับ NPC ที่อยู่ใกล้ และไปบทพูดถัดไป |
| `R` | เริ่มวัดระยะใหม่จากจุดที่ยืน |
| `G` | เปิด/ปิดเส้นตาราง (เส้นบาง = 10 ม., เส้นหนา = 100 ม.) |
| `M` / `Esc` | เปิด/ปิดแผนที่สำรวจ (มาตราส่วน 1:10,000) |

## วิธีทดสอบต้นแบบ (ด้วยตนเอง)

1. `npm run dev` แล้วเปิด http://localhost:5173
2. เดินด้วย WASD หรือปุ่มลูกศร → กล้องเลื่อนตามตัวละคร หมอกรอบตัวเปิดออก
3. เดินชนกำแพงรั้วโรงเรียน ต้นไม้ อาคาร หรือลำห้วย → ต้องเดินผ่านไม่ได้ และ "ระยะทางรวม" ต้องไม่เพิ่มขึ้นขณะดันกำแพง
4. เดินเข้าใกล้ **ครูเนม** (มีเครื่องหมาย ! เหนือหัว) กด `E` → ฟังบทพูด ซึ่งบอกทิศและระยะเส้นตรงไปศาลาชุมชน
5. กด `R` เริ่มวัดระยะ แล้วเดินออกประตูโรงเรียน → ถนนหลัก → ข้ามสะพาน → ไปทางตะวันออกจนถึงศาลาชุมชน
   เทียบ "ระยะที่วัด" (ระยะเดินจริง ~560 ม.) กับระยะเส้นตรงที่ครูบอก (~310 ม.)
6. คุยกับ **ผู้ใหญ่บ้าน** ที่ลานหน้าศาลา → กล่องภารกิจด้านบนเปลี่ยนเป็นฉาก 3/6
7. กด `G` ดูตาราง แล้วนับช่องเทียบกับแถบมาตราส่วน 50 ม. (5 ช่อง) มุมซ้ายล่าง
8. กด `M` เปิดแผนที่ → แสดงเฉพาะพื้นที่ที่สำรวจแล้ว พร้อมจุดสังเกตที่ค้นพบ เส้นตาราง 100 ม. และแถบมาตราส่วน

## โครงสร้างโปรเจกต์

ดูรายละเอียดสถาปัตยกรรม กติกามาตราส่วน และมาตรฐานไฟล์ภาพได้ที่ [GAME_DESIGN.md](./GAME_DESIGN.md)

```
src/core/      ระบบเกม (TypeScript ล้วน ทดสอบได้) — มาตราส่วน ระยะทาง ทิศ หมอก แผนที่
src/content/   เนื้อหาด่าน (ข้อมูลล้วน) — เพิ่มตำบลใหม่ที่นี่
src/scenes/    ฉาก Phaser — Boot / World / UI
src/graphics/  ภาพ placeholder และลำดับ tile
tests/         unit test
```
