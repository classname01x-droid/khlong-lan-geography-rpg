# Geography Mystery RPG: ปริศนาลับแห่งคลองลาน

เกมสืบสวนภูมิศาสตร์ 2D Pixel Art (Top-down) สำหรับนักเรียน ใช้พื้นที่ 4 ตำบลในอำเภอคลองลานเป็นฉาก
ผู้เล่นใช้ **ทิศทาง มาตราส่วน ระยะทาง และจุดสังเกต** เพื่อแก้ปริศนา และรวบรวมรหัสลับจากทั้ง 4 ตำบล

> **v0.22 คลองลาน — ตำนานพญาจระเข้ผู้พิทักษ์ (RPG):** ภารกิจเรียบง่าย (1 NPC = 1 ปัญหา = 1 คำถาม 3 ตัวเลือก) ได้เหรียญ + ศรัทธา · Golden Time 5 นาที · ร้านค้า · ต่อสู้พญาจระเข้แบบเลือกคำสั่ง (ชำระมลพิษ ไม่ใช่สังหาร) · Intro/ฉากจบมีแอนิเมชัน · ไม่มีหีบ/รหัสลับอีกต่อไป — ดู GAME_DESIGN.md หัวข้อ 0
> สถานะเดิม: **v0.20** — **เกมผจญภัยแบบภารกิจหลักต่อเนื่อง เล่นได้ตั้งแต่เริ่มเรื่องจนจบเกม**: นักสำรวจของครูเนมเดินทาง
> บทที่ 1 สักงาม → 2 คลองน้ำไหล → 3 โป่งน้ำร้อน → 4 คลองลานพัฒนา → 5 ปริศนาสุดท้าย (โรงเรียนบ้านสักงาม) → ฉากจบและสรุปผลการเรียนรู้
> ภาพทั้งหมดเป็น placeholder ที่สร้างด้วยโค้ด · ผังแผนที่และเนื้อหาภูมิปัญญายังเป็นข้อมูลสมมติที่ต้องตรวจกับชุมชน
> **เล่นบนมือถือได้ (Mobile-First):** จอยสติก 8 ทิศ ปุ่มสัมผัสตามสถานการณ์ แถบติดตามภารกิจมุมขวาบน และคำใบ้แบบเป็นขั้น — คีย์บอร์ดยังใช้ได้ครบ
> **v0.21 ตำนานพญาจระเข้ผู้พิทักษ์คลองลาน:** เปลี่ยนเรื่องหีบสมบัติเป็นตำนาน — เกมใหม่เริ่มด้วย Intro 3 ฉาก (คลองลานในอดีต → มนุษย์ทำลายป่า/ปล่อยสารเคมี พญาจระเข้พิโรธ → ผู้เล่นเป็นผู้นำชุมชนคนใหม่) แตะเพื่อไปต่อหรือ "ข้าม" · รหัส 4 ชิ้นเดิมกลายเป็น "คำพิทักษ์" 4 คำ · บทที่ 5 วางคำพิทักษ์ที่ศาลพญาจระเข้เพื่อชำระมลพิษ · แผนที่ การเดิน NPC ภารกิจภูมิศาสตร์ และบันทึกเดิมไม่เปลี่ยน (ภาพ Intro: `public/intro/`)
> **v0.20 บทที่ 3 "ปริศนาเมืองโบราณใต้ผืนดิน" (แบบเรียบง่าย):** เปิดแผนที่เส้นชั้นความสูง → แตะเลือกพื้นที่ (วงกลมรัศมี 40 ม. · เลือกใหม่/ยกเลิกได้) → ยืนยัน → คะแนน 2 เกณฑ์เท่านั้น: **ระดับความสูง 50** (สูงกว่าลำน้ำกี่เมตร) + **ระยะจากแหล่งน้ำ 50** = 100 · ผ่านเมื่อ**มากกว่า 70** (คำนวณจากแผนที่จริง ไม่สุ่ม ไม่มีความลาดชัน) → ไม่ผ่านกลับไปพบครูเนม (อธิบายเฉพาะเกณฑ์ที่พลาด) → ผ่านแล้วออกสำรวจหาหลักฐานจำลอง → รหัส "พิกัด" · **เมืองโบราณเป็นสถานการณ์จำลอง คะแนนคือความเหมาะสมตามเงื่อนไขจำลอง ไม่ใช่โอกาสพบเมืองจริง** · บันทึกกลางบทที่ 3 รุ่นก่อนเริ่มบทใหม่พร้อมแจ้ง (บท 1–2/รหัส/ปลดล็อกไม่กระทบ) — ดู GAME_DESIGN.md หัวข้อ 25
> **v0.19 นำทางด้วยการกระทำ:** แถบภารกิจทุกตำบลบอก เป้าหมายปัจจุบัน · เครื่องมือ · วิธีทำทีละข้อ (แตะ/กดปุ่มไหน — คำตามอุปกรณ์) · เมื่อสำเร็จจะเกิดอะไร พร้อม **ปุ่มลัด** เปิดเครื่องมือทันที · NPC เป้าหมายมี ! เฉพาะคนเดียว + ลูกศรขอบจอ + จุดบนแผนที่ (ไม่นำทางไปสถานที่ลับ) · **วัดระยะจากจุดอ้างอิงของภารกิจ** (เช่น "ระยะจากศาลาชุมชน: 120 เมตร") พร้อมเส้นวัดบนจอและบนแผนที่ · บทที่ 1 = ช่วงรับภารกิจ 3 ขั้น + ช่วงตามหาแหล่งผ้าปัก 13 ขั้น
> **v0.18 ปักหมุดบนมือถือ:** แตะแผนที่ = ย้ายหมุด · ลากหมุดด้วยนิ้ว · ลากที่อื่น = เลื่อนแผนที่ · ปุ่มลูกศร ▲ เหนือ ▼ ใต้ ◀ ตก ▶ ออก (ครั้งละ 1 ช่อง) · ป้ายพิกัด X/Y (หรือ E/N) เหนือหมุดอัปเดตทันที — ใช้ได้ทุกมือถือ/แท็บเล็ต/คอมพิวเตอร์
> **v0.17 ปริศนาหีบสมบัติ:** ครูเนมพบหีบไม้เก่าที่มีช่องรหัส 4 ช่อง — ทุกบทคือการตามหารหัส 1 ชิ้น ครบแล้วกลับมาเปิดหีบ (เรื่องแต่งในเกม) · บทที่ 1 แบ่งเป็น 13 ขั้นย่อย แถบภารกิจบอก "ตอนนี้ · วิธีทำ · ขั้น x/13 · ขอคำแนะนำ (3 ระดับ)" · สมุดหน้าภารกิจแสดงขั้นที่ทำแล้วและข้อมูลจากชาวบ้าน
> **v0.16 พร้อมทดลองกับนักเรียน:** ป้าย "คุย" ย้ายไปที่ว่างเองเมื่อแถบภารกิจบัง · ป้ายชื่อ NPC/สถานที่ไม่ทับกัน · บทแนะนำย่อเป็นแถบสั้นเมื่อเปิดแผนที่/สมุด · แก้ตัวละครเดินช้าช่วงแรกบนเครื่องที่ช้า (ดู "บันทึกการแก้ไข v0.16")
> **v0.15 บทแนะนำผู้เล่นใหม่:** เริ่มเกมครั้งแรก ครูเนมพาฝึกทีละขั้น — เดินด้วยจอยสติก เข้าใกล้ครูเนม กดคุย เปิดสมุด เปิดแผนที่ และวัดระยะ (การ์ดข้อความสั้น + ปุ่มที่ต้องใช้กะพริบ) · ข้ามได้ (แตะ 2 ครั้ง) โดยภารกิจหลักไม่ถูกข้าม · ป้ายชื่อ NPC/สถานที่อ่านได้บนโทรศัพท์ · เข้าใกล้ NPC มีป้าย "คุย" เหนือหัว
> **v0.14 หน้าจอนอกด่านสำหรับมือถือ:** เมนูหลัก แผนที่การเดินทาง ฉากเชื่อมบท และฉากจบ เป็นหน้าจอตัวอักษรใหญ่ ปุ่ม ≥ 48 px เว้นรอยบาก · แถบภารกิจแสดงคำแนะนำสั้นตั้งแต่เริ่มฉาก
> **v0.13 อ่านง่ายบนโทรศัพท์:** สมุดภาคสนาม กระดานวิเคราะห์ หลักฐานเปรียบเทียบแผนที่ หน้าสรุป และเมนูหยุดเกม เป็นหน้าอ่านตัวอักษรใหญ่ (แท็บ + เลื่อนอ่าน) · แผนที่ขยาย/ลากเลื่อนได้ พร้อมแผงคำอธิบายสัญลักษณ์

## เริ่มต้นใช้งาน

ต้องใช้ Node.js 22.12 ขึ้นไป

```bash
npm install
npm run dev        # เปิด http://localhost:5173
```

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `npm run dev` | รันเกมโหมดพัฒนา (แก้โค้ดแล้วรีโหลดอัตโนมัติ) |
| `npm test` | รัน unit test (มาตราส่วน ระยะทาง ทิศ หมอก เส้นทาง ภารกิจ เบาะแส ปักหมุด จบด่าน บันทึกความคืบหน้า ปุ่มสัมผัส แถบภารกิจ คำใบ้) |
| `npm run typecheck` | ตรวจ TypeScript |
| `npm run build` | ตรวจ type แล้ว build ไปที่ `dist/` |
| `npm run preview` | เปิดไฟล์ที่ build แล้ว |

## การควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| `W A S D` / ปุ่มลูกศร | เดิน (เดินทแยงได้) |
| `E` / `Space` / `Enter` | คุยกับ NPC ที่อยู่ใกล้ / ตรวจค้นจุดที่ยืนอยู่ / ไปบทพูดถัดไป |
| `1` `2` `3` | ตอบคำถามเลือกตอบ / เลือกเส้นทางในสมุด / เลือกประเภทภูมิปัญญาตอนปักหมุด |
| `R` | วัดระยะ: ขั้นที่ภารกิจกำหนดจุดอ้างอิง → วัดจากจุดนั้น (เช่น ศาลาชุมชน) · นอกนั้นวัดจากจุดที่ยืน |
| `G` | เปิด/ปิดเส้นตาราง (เส้นบาง = 10 ม., เส้นหนา = 100 ม.) |
| `N` | เปิด/ปิดสมุดภาคสนาม: ภารกิจ / เบาะแส / วิเคราะห์เส้นทาง / หลักฐาน (`◀ ▶` หรือ `A` `D` เปลี่ยนหน้า) |
| `Delete` ×2 | (ในหน้า หลักฐาน/ข้อความ) เริ่มด่านนี้ใหม่ |
| `Esc` | ในด่าน: เมนูหยุดเกม (แผนที่การเดินทาง / เมนูหลัก) · หน้าสรุปผล: แผนที่การเดินทาง (`Enter` = รับภารกิจบทถัดไป) |
| `Tab` (ในแผนที่) | สลับแผนที่สำรวจ ↔ แผนที่ฐานแต่ละฉบับ (ด่าน 2) |
| `C` | ปุ่มวิเคราะห์: บท 1 กระดานวิเคราะห์เส้นทาง · บท 2 เปรียบเทียบแผนที่ฐาน · บท 3–4 กระดานวิเคราะห์ |
| คลิกปุ่มบนแถบภารกิจ | ปุ่มลัดของขั้นนี้ (เปิดแผนที่/สมุด/กระดาน/วัดระยะ/ปักหมุด) · 💡 ขอคำแนะนำ |
| `↑ ↓` + `Enter` / เมาส์ | เลือกในเมนูหลัก แผนที่การเดินทาง ฉากเชื่อมเรื่อง และหน้าต่างยืนยัน |
| `M` / `Esc` | เปิด/ปิดแผนที่สำรวจ (มาตราส่วน 1:10,000) — ในโหมดปักหมุดใช้ `WASD`/ลูกศรเลื่อนหมุด และ `Space` ปัก |

### เล่นบนมือถือ / แท็บเล็ต (จอสัมผัส)

ถือโทรศัพท์**แนวนอน** (ถ้าถือแนวตั้งเกมจะหยุดชั่วคราวและบอกให้หมุนจอ — ความคืบหน้าไม่หาย)

| บนจอ | ทำอะไร | เทียบคีย์บอร์ด |
|---|---|---|
| จอยสติก "เดิน" (ซ้ายล่าง แตะตรงไหนในโซนซ้ายก็ได้) | เดิน 8 ทิศ · ยกนิ้ว/สลับแอป = หยุดเดิน | `WASD` |
| ปุ่มใหญ่สีเหลือง ✋ (เช่น "คุย" / "สำรวจ" / "ตรวจสอบ") | โต้ตอบกับสิ่งที่อยู่ใกล้ที่สุด — กดไม่ได้เมื่อไม่มีอะไรในระยะ | `E` |
| 🗺️ แผนที่ · 📒 สมุด · 📏 วัดระยะ · 🔍 วิเคราะห์/เทียบแผนที่ · # ตาราง · ☰ เมนู | ตามชื่อปุ่ม (ปุ่มวิเคราะห์มีเฉพาะด่านที่ใช้) | `M` `N` `R` `C` `G` `Esc` |
| แตะกล่องบทสนทนา | อ่านบรรทัดถัดไป | `Space` |
| ปุ่มคำตอบขนาดใหญ่ | ตอบคำถาม / เลือกเส้นทาง / เลือกประเภทภูมิปัญญา / เลือกจุด A B C | `1` `2` `3` |
| ในแผนที่: แตะช่องบนแผนที่ แล้ว 📍 ปักหมุดตรงนี้ · 🔁 สลับแผ่น | ปักหมุด / สลับแผนที่ฐาน | ลูกศร + `Space` · `Tab` |
| ในแผนที่: ＋ ขยาย / － ย่อ · ลากนิ้วเพื่อเลื่อน · 📖 สัญลักษณ์ | อ่านชื่อสถานที่บนจอเล็ก (มาตราส่วนและพิกัดเดิม — แถบ 100 ม. ยาวตามการขยาย) | — |
| สมุด / กระดานวิเคราะห์ / เปรียบเทียบแผนที่: แตะแท็บด้านบน · ลากนิ้วขึ้นลงเพื่ออ่านต่อ | หน้าอ่านตัวอักษรใหญ่ (ไม่ย่อทั้งหน้าต่าง) | `◀ ▶` |
| ☰ เมนู → ปุ่มใหญ่ เล่นต่อ / แผนที่การเดินทาง / กลับเมนูหลัก | เมนูหยุดเกม | `Esc` แล้ว `1` `3` `4` |
| เมนูหลัก: ปุ่มใหญ่ เริ่มเกมใหม่ · เล่นต่อ (บอกว่าจะไปบทไหน) · แผนที่การเดินทาง · วิธีเล่น (แท็บ) · ตั้งค่า | หน้าแรกของเกม | `↑ ↓` + `Enter` |
| แผนที่การเดินทาง: แตะบทเพื่อดูข้อมูล · ปุ่มเหลืองปุ่มเดียว "เดินทางต่อ/เล่นต่อ" | ดูความคืบหน้า (ไม่ใช่หน้าเลือกด่าน) | `Enter` · `Esc` |
| ฉากเชื่อมบท: ▶ อ่านต่อ · ◀ ย้อน · ▶ ออกเดินทาง (กดได้หลังอ่านจบครู่หนึ่ง) | อ่านบทสนทนาและเป้าหมายภารกิจใหม่ | `Space` |
| แถบภารกิจมุมขวาบน: ปุ่มลัดสีเขียว (เช่น "🔍 เปิดกระดานวิเคราะห์" / "✋ คุยกับป้าศรี") · 💡 ขอคำแนะนำ · ▴ ย่อ | ทำขั้นปัจจุบันได้ทันที / ขอคำใบ้ระดับ 2–3 | — |
| แถบวัดระยะ (ซ้ายบน เมื่อกำลังวัด): ↺ วัดใหม่ · ✕ หยุด | ดูระยะจากจุดเริ่มวัด · เริ่มวัดใหม่จากจุดที่ยืน (เมื่อภารกิจอนุญาต) | `R` |

เครื่องที่ตรวจพบจอสัมผัสจะแสดงปุ่มอัตโนมัติ · บังคับได้ด้วย `?touch=1` (แสดงปุ่มบนคอมพิวเตอร์) หรือ `?touch=0` (ซ่อนปุ่ม)

## บันทึกการแก้ไข v0.18: ปักหมุดบนแผนที่ (มือถือทุกรุ่น)

**ปัญหา:** เข้าโหมดปักหมุดแล้วขยับหมุดไม่ได้บนโทรศัพท์

**สาเหตุ:** ตัวแยก "แตะ" กับ "ลาก" บนแผนที่ใช้ระยะ 12 หน่วยของภาพเกม (960×640) แต่บนโทรศัพท์ภาพเกมถูกย่อเหลือ 0.4–0.65 เท่า 12 หน่วยจึงเท่ากับนิ้วขยับเพียง 5–8 CSS px — การแตะปกติของนิ้วสั่นเกินนั้น จึงถูกนับเป็น "เลื่อนแผนที่" แทน "ย้ายหมุด" และการลากทุกครั้งเลื่อนแผนที่ (ไม่มีทางลากหมุด) · การทดสอบอัตโนมัติเดิมแตะแบบนิ้วไม่สั่น จึงไม่พบ

**การแก้ไข (`core/ui/PinGesture.ts` + ชั้นแตะแผนที่ใน `TouchLayer`):**
- ชั้น DOM ครอบแผนที่ รับ Pointer Events (มือถือ/แท็บเล็ต/เมาส์) · `touch-action: none` · กัน touchstart/touchmove ของเบราว์เซอร์ (passive: false) ไม่ให้หน้าเลื่อน/ซูมจากการแตะสองครั้ง
- วัดระยะเป็น **CSS px ของจอจริง**: นิ้วขยับไม่เกิน 14 px = แตะ → หมุดไปช่องที่ "นิ้ววางลง"
- เริ่มแตะบนหมุด (รัศมีอย่างน้อย 28 px) แล้วลาก = ลากหมุดตามนิ้ว · เริ่มที่อื่นแล้วลาก = เลื่อนแผนที่ (หมุดไม่ขยับ)
- พิกัดคำนวณจาก `getBoundingClientRect()` ของ canvas ณ ตอนแตะทุกครั้ง แล้วแปลงตามระดับขยาย/การเลื่อนแผนที่ (ไม่ใช้ค่าที่จำไว้ ซึ่งคลาดได้เมื่อแถบที่อยู่ของเบราว์เซอร์ยุบ/ขยาย)
- สัมผัสถูกยกเลิก (pointercancel / เสียการจับนิ้ว) → ล้างสถานะ การแตะครั้งต่อไปใช้ได้เสมอ · นิ้วที่สองถูกละไว้
- ปุ่มลูกศร 4 ทิศ ▲ เหนือ ▼ ใต้ ◀ ตก ▶ ออก ครั้งละ 1 ช่อง (ส่งรหัสลูกศรเดียวกับคีย์บอร์ด) · ปุ่ม ≥ 44×44
- ป้ายพิกัด "📍 X · Y" (บทที่ใช้พิกัดกริดแสดง E/N) เหนือหมุด อัปเดตทันทีขณะลาก · แถบล่างของแผนที่แสดงพิกัดเดียวกัน
- "ปักหมุดตรงนี้" ใช้ตำแหน่งล่าสุดของหมุด → ตรวจพิกัด ประเภทภูมิปัญญา และหลักฐานด้วย `submitPin` เดิม (ไม่ได้เปลี่ยนเฉลยหรือเกณฑ์ตรวจ)
- คอมพิวเตอร์: คลิกแผนที่ = ย้ายหมุด · ลากหมุดด้วยเมาส์ · ลูกศร/WASD ทีละช่อง · Space ยืนยัน (เหมือนเดิม)
- หน้าเปรียบเทียบแผนที่: ระยะลากวัดเป็น CSS px เช่นกัน

## v0.19 นำทางด้วยการกระทำ (Action Guidance) และวัดระยะจากจุดอ้างอิง

**ปัญหาจากการเล่นจริง:** แถบภารกิจบอก "ต้องทำอะไร" แต่ไม่บอกว่า "กดปุ่มไหน เปิดหน้าไหน" (เช่น ขั้น "เลือกเส้นทางที่ตรงกับข้อมูล" แต่หาไม่เจอว่ากระดานวิเคราะห์อยู่ที่ไหน) · หา NPC ที่ต้องไปพบไม่เจอ · ตัวเลขวัดระยะไม่บอกว่าวัดจากจุดใด

**แถบภารกิจ (ทุกตำบล ทุกขั้น):**

```
📜 ภารกิจหลัก: ตามหารหัสหีบสมบัติชิ้นแรก · ช่วงที่ 2 · ตามหาแหล่งผ้าปัก
🎯 เป้าหมายปัจจุบัน: เปิดกระดานวิเคราะห์เส้นทาง        ความคืบหน้า 6/13 ขั้น
🧰 เครื่องมือ: กระดานวิเคราะห์เส้นทาง
👉 1 แตะปุ่ม "🔍 เปิดกระดานวิเคราะห์เส้นทาง" บนแถบภารกิจนี้ (หรือแตะปุ่ม "🔍 วิเคราะห์")
👉 2 ดูข้อมูลเส้นทาง ก ข และ ค
👉 3 เทียบทิศทาง ระยะทาง และสะพาน กับเบาะแสด้านบนของกระดาน
✅ เมื่อสำเร็จ: เมื่อกระดานเปิดแล้ว ขั้นต่อไปคือเลือกเส้นทาง
[🔍 เปิดกระดานวิเคราะห์เส้นทาง]  [💡]  [▴]
```

- คำบอกปุ่มเขียนครั้งเดียว (`{tap:routes}`) แปลงตามอุปกรณ์: มือถือ "แตะปุ่ม 🔍 วิเคราะห์" · คอมพิวเตอร์ "กด C (กระดานวิเคราะห์เส้นทาง)" — ไม่ต้องจำปุ่มคีย์บอร์ดบนมือถือ
- ปุ่มลัด: เปิดแผนที่ / สมุดหน้าที่เกี่ยวข้อง / กระดานวิเคราะห์ / เริ่มวัดระยะ / แผนที่โหมดปักหมุด / ดูเป้าหมายบนแผนที่ · เข้าใกล้เป้าหมายแล้วเปลี่ยนเป็น "✋ คุย…" · ปุ่มเครื่องมือจริงบนจอสัมผัสที่ต้องใช้กะพริบสีเขียว
- 💡 ขอคำแนะนำ: ระดับ 1 = วิธีทำ (แสดงตลอด) → ระดับ 2 = ใช้เครื่องมืออะไรอย่างไร → ระดับ 3 = คำถามช่วยคิด (ไม่เฉลยตำแหน่งลับ เส้นทางที่ถูก หรือคำตอบ)
- จอเตี้ย: แถบภารกิจอยู่ครึ่งขวาของภาพ (ไม่บังตัวผู้เล่นกลางจอ) สูงได้มากขึ้นเพื่อให้เห็นวิธีทำครบ · ปุ่มอยู่แถวเดียว

**นำทางไป NPC (เฉพาะที่มีคนบอกตำแหน่งแล้ว):** เครื่องหมาย ! เฉพาะ NPC เป้าหมาย (ชื่อสีเหลือง) · ลูกศรขอบจอ "ป้าศรี 200 ม." เมื่ออยู่นอกจอ (หลบแถบบนจอ) · ป้าย "! ชื่อ" เหนือหมอกเมื่ออยู่ในจอแต่ยังไม่สำรวจ · บนแผนที่ "! ป้าศรี (เป้าหมาย)" · เข้าใกล้ ≤ 4 ช่อง = "ไปพบ" สำเร็จ · ปุ่มคุยเมื่ออยู่ในระยะ
สถานที่ลับ/คำตอบ (บ้านผ้าปักก่อนค้นพบ จุดปริศนา จุดคำตอบของกระดานวิเคราะห์ หินสามก้อน จุด A/B/C ที่ต้องหาจากพิกัด) **ไม่มีการนำทาง** — `validateLevel` และ unit test ตรวจทุกตำบล

**วัดระยะแบบตามภารกิจ:** ขั้นที่ภารกิจกำหนดจุดอ้างอิง (`measure: { from: 'sala' }`) ปุ่มวัดระยะเริ่มวัดจากจุดนั้นเอง → เส้นประสีเหลืองจากจุดเริ่มวัดถึงตัวผู้เล่น (บนจอและบนแผนที่) · แถบวัดระยะ "ระยะจากศาลาชุมชน: 120 เมตร · 12 ช่อง = 1.2 ซม. บนแผนที่ · เดินจริง 160 ม." เปลี่ยนตามตำแหน่งจริงทุกเฟรม (ScaleSystem เดิม 1 ช่อง = 10 ม. · 1:10,000)
แยก 4 ระยะไม่ปนกัน: ระยะเดินสะสมทั้งบท (สมุด หน้าหลักฐาน/สถิติ) · ระยะเส้นตรงระหว่างสองสถานที่ (เบาะแส) · ระยะตามถนน (กระดานวิเคราะห์เส้นทาง) · ระยะวัดจากจุดอ้างอิง (แถบวัดระยะ)
"↺ วัดใหม่จากตรงนี้" มีเฉพาะเมื่อภารกิจอนุญาต (ปริศนาลายผ้า) — ขั้นวัดจากศาลาจุดอ้างอิงคงที่ · ออกจากเกมแล้วกลับมา ยังวัดจากจุดเดิม (จาก flag `measured:<จุด>` ในบันทึกเดิม)

**แถบบนจอระหว่างเล่น:** เหลือแถบภารกิจ · เข็มทิศ/ทิศที่หัน (+ พิกัดในบทที่ใช้พิกัดกริด) · แถบวัดระยะเมื่อกำลังวัด · การแจ้งเตือน — ระยะเดินสะสม พื้นที่สำรวจ เวลา ย้ายไปสมุด หน้า "หลักฐาน/ข้อความ" (สถิติการสำรวจ)

**สมุดภาคสนาม:** เบาะแสจดอัตโนมัติ เรียงตามลำดับที่ได้รับ · ระบุผู้ให้ข้อมูล · ไอคอนประเภท (🧭 ทิศทาง 📏 ระยะทาง 📍 จุดสังเกต ⛰️ ความสูง 🗺️ สัญลักษณ์ 🔢 พิกัด) · ★ ใหม่ = เพิ่งได้ · ปุ่มลัด "เปิดสมุด" เปิดหน้าเบาะแสให้เลย · กระดานวิเคราะห์เส้นทางแสดง "ข้อมูลที่ใช้เปรียบเทียบ" จากเบาะแสที่ได้ไว้บนสุด · หน้าภารกิจแสดงทุกขั้นแยกตามช่วง (✓ ทำแล้ว ▶ ตอนนี้ ○ ยังไม่ถึง) พร้อมวิธีทำ เครื่องมือ และผลเมื่อสำเร็จ

| ป้าย "▼ คุย" ถูกแถบภารกิจบัง เมื่อ NPC อยู่ขวาบนของจอ | ป้ายอยู่ในโลกเกม (canvas) ส่วนแถบภารกิจเป็น DOM ซ้อนด้านบน — ป้ายไม่รู้ว่าแถบอยู่ตรงไหน | ชั้นปุ่ม (TouchLayer) ส่งพื้นที่ของแถบภารกิจ แถบสถานะ การ์ดบทแนะนำ ข้อความโต้ตอบ และปุ่มที่ซ้อนบนภาพ ให้ฉากเกม → ป้ายเลือกตำแหน่ง เหนือ → ขวา → ซ้าย → ใต้ NPC ที่ว่างและอยู่ในจอ (ลูกศรชี้ไปที่ NPC) · แถบภารกิจไม่ถูกซ่อน |
| ชื่อ NPC และชื่อสถานที่ซ้อนกัน (เช่น บริเวณศาลาชุมชน) | ป้ายวางตามพิกัดอย่างเดียว ไม่มีการตรวจการชน และ v0.15 ขยายตัวอักษรบนโทรศัพท์ | จัดป้ายตามความสำคัญ: เป้าหมายที่คุยได้ → NPC ใกล้ผู้เล่น → สถานที่ใกล้ผู้เล่น ป้ายที่ชนเลื่อนขึ้น/ลง หรือซ่อนชั่วคราว (ป้ายที่ไกลกว่าถูกซ่อนก่อน) · ป้ายที่ถูกแถบบนจอบังก็เลื่อน/ซ่อนเช่นกัน · ระบบนี้ซ่อน/เลื่อนได้อย่างเดียว ชื่อสถานที่ลับที่ยังไม่ค้นพบจึงไม่มีทางปรากฏ |
| การ์ดบทแนะนำบังเนื้อหาสมุด/แผนที่ | การ์ดใช้ตำแหน่งขอบล่างเหมือนตอนเดินสำรวจ | เปิดสมุด/แผนที่ → ย่อเป็นแถบคำแนะนำสั้น: จอสัมผัส = ส่วนบนของคอลัมน์ปุ่มขวา (เหนือปุ่ม) · คอมพิวเตอร์ = บรรทัดเดียวใต้กรอบสมุด/แผนที่ · การ์ดตอนเดินบนคอมพิวเตอร์อยู่ระหว่างแถบมาตราส่วนกับเข็มทิศ และตอนคุยอยู่ทางขวาของแผงข้อมูล |
| กด D ค้างแล้วตัวละครไม่เดินในการทดสอบครั้งแรก | **ไม่ใช่ปุ่มหาย** — ปุ่มถูกกดอยู่ทุกเฟรม แต่ Phaser ตัดเวลาต่อเฟรมไม่เกิน 1/60 วินาทีใน 120 เฟรมแรกหลังเกมเริ่ม/กลับมาที่หน้าต่าง (`fps.panicMax`) เครื่องที่ทำงานหนัก (~20 fps) 120 เฟรม = 6 วินาที ทั้งเกมจึงเดินช้าลง ~3 เท่า (ตัวละครขยับ 9–11 ม. แทน ~28 ม.) — การทดสอบครั้งนั้นรันพร้อมชุดทดสอบ 11 จอ | ตั้ง `fps.panicMax = 0` (`GAME_FPS` ใน `src/config/constants.ts`) — ไม่ได้เพิ่มคำสั่งเดินซ้ำ · ยังมีการป้องกันเฟรมยาวผิดปกติ (> 200 ms) และฟิสิกส์คำนวณทีละ 1/60 วินาทีเหมือนเดิม · ผลหลังแก้ในสภาพเดียวกัน: เดิน 27–37 ม. ผ่าน 8/8 |

การทดสอบที่เพิ่ม: ปุ่ม WASD และลูกศร (กดสั้น/กดค้าง/ปล่อย), ทแยง, กดค้างแล้วหยุดเกม, สลับหน้าต่างขณะกดค้าง, คลิกปุ่มด้วยเมาส์แล้วใช้คีย์บอร์ดต่อ, ความเร็วเดินตรงกับเวลาจริงขณะเครื่องทำงานหนัก · ป้าย "คุย" ไม่ถูกบังที่หลายตำแหน่งรอบ NPC · ป้ายชื่อที่แสดงไม่ทับกัน · แถบบทแนะนำไม่ทับเนื้อหา/ปุ่ม (11 ขนาดจอ + คอมพิวเตอร์ 2 ขนาด)

## วิธีทดสอบ: เล่นบนมือถือ (v0.12–v0.19)

ทดสอบบนคอมพิวเตอร์: Chrome DevTools → Toggle device toolbar → เลือกโทรศัพท์ → หมุนเป็นแนวนอน → รีโหลด (ปุ่มจะขึ้นเมื่อมีจอสัมผัส)

ทดสอบบนโทรศัพท์จริง: `npm run build` แล้ว deploy โฟลเดอร์ `dist/` (เช่น Vercel/Netlify) หรือ `npm run dev -- --host` แล้วเปิดจาก IP ของเครื่องในวง Wi-Fi เดียวกัน

สิ่งที่ต้องตรวจด้วยมือบนเครื่องจริง (ยังไม่ได้ทดสอบบนโทรศัพท์จริง — ทดสอบอัตโนมัติด้วยการจำลองจอสัมผัสเท่านั้น):
1. iPhone (Safari) และ Android (Chrome) แนวนอน: จอยสติกเดินได้ 8 ทิศ ยกนิ้วแล้วหยุดทันที · เดินพร้อมกดปุ่มอื่นได้ (สองนิ้ว)
2. รุ่นที่มีรอยบาก/Dynamic Island: ปุ่มและภาพเกมไม่ถูกรอยบากบัง ทั้งหมุนซ้ายและหมุนขวา
3. แตะสองครั้งเร็ว ๆ / บีบนิ้ว: หน้าเว็บต้องไม่ซูมหรือเลื่อน · ปุ่มเดียวกันแตะครั้งเดียวทำงานครั้งเดียว
4. หมุนเป็นแนวตั้งระหว่างเล่น → ขึ้นหน้า "กรุณาหมุนโทรศัพท์" → หมุนกลับ → อยู่ที่เดิม
5. สลับแอป/ล็อกจอระหว่างกดจอยสติก → กลับมาแล้วตัวละครต้องไม่เดินเอง · ปิดแท็บแล้วเปิดใหม่ → เล่นต่อจากเดิม
6. อ่านเบาะแสในสมุด กระดานวิเคราะห์ และชื่อสถานที่บนแผนที่ (ระดับขยายเริ่มต้น) บนจอ 5–6 นิ้วได้สบายตาหรือไม่ · ลากเลื่อนอ่านในหน้าอ่านลื่นหรือไม่ (iOS Safari)
7. แผนที่: ลากเลื่อนแล้วหมุดไม่ย้ายเอง · แตะช่องแล้วหมุดไปถูกช่อง (ทุกระดับขยาย) · แผงสัญลักษณ์ตรงกับสัญลักษณ์บนแผนที่
8. ความลื่นไหล (FPS) และความร้อนของเครื่องเมื่อเล่นนาน 15 นาทีขึ้นไป · แบตเตอรี่/ประหยัดพลังงาน (Low Power Mode)
9. ขนาดตัวอักษรของระบบ (Dynamic Type / ขนาดตัวอักษร Android) และโหมดมืด ไม่ทำให้ปุ่มหรือหน้าอ่านล้นจอ
10. เมนูหลัก → เริ่มเกมใหม่ → ฉากเชื่อมบท → ออกเดินทาง ทำได้ด้วยนิ้วเดียว · นักเรียนเข้าใจเองหรือไม่ว่าต้องกดอะไรต่อ (ทดสอบกับผู้เล่นจริง)
11. ฉากจบ: เลื่อนอ่านแผนที่ภูมิปัญญาและผลการเรียนรู้ได้ครบบน iPhone SE/จอเล็ก
12. บทแนะนำ: นักเรียนที่ไม่เคยเล่นทำตามการ์ดได้เองครบ 8 ขั้นหรือไม่ (จับเวลา · ขั้นไหนติด) · ปุ่มที่กะพริบมองเห็นชัดกลางแดด/จอสว่างต่ำ
13. ป้ายชื่อ NPC/สถานที่และป้าย "คุย" อ่านได้บนจอ 5–6 นิ้ว และไม่บังตัวละครมากเกินไป
14. เดินเข้าหา NPC จากหลายทิศ (โดยเฉพาะเมื่อ NPC อยู่ขวาบนของจอ) ป้าย "คุย" ยังเห็นเสมอ · ป้ายที่เลื่อน/ซ่อนชั่วคราวไม่กระพริบจนรบกวน
15. เครื่องสเปกต่ำ: เดินด้วยจอยสติก/คีย์บอร์ดทันทีหลังเข้าด่านและหลังสลับแอปกลับมา ความเร็วต้องเท่ากับตอนเล่นปกติ
16. (เกณฑ์หลัก v0.17) นักเรียนที่ไม่เคยเล่นอธิบายได้ภายใน 1 นาทีว่า "กำลังตามหารหัสเปิดหีบ" และบอกได้จากแถบภารกิจว่าต้องทำอะไรต่อ · จับเวลาแต่ละขั้น 1–13 ว่าขั้นไหนติดนาน
17. แตะ "ขอคำแนะนำ" ครบ 3 ระดับแล้วยังต้องคิดเอง (ไม่ได้คำตอบ) · ตอบผิดแล้วคำใบ้ช่วยได้จริง
18. (v0.18) ปักหมุดบน iPhone (Safari) และ Android (Chrome) จริง: แตะเร็ว ๆ แบบเด็ก ๆ หมุดย้ายทุกครั้ง · ลากหมุดได้ · ลากที่ว่างเลื่อนแผนที่ · ลูกศรครั้งละ 1 ช่อง · พิกัดบนป้ายตรงกับตำแหน่งหมุด · หลังแถบที่อยู่ของ Safari ยุบ/ขยายแล้วยังแตะถูกช่อง
19. (v0.19) ให้นักเรียนที่ไม่เคยเล่นเล่นบทที่ 1 เอง โดยครูไม่บอก: ทุกครั้งที่เป้าหมายเปลี่ยน ถามนักเรียนว่า "ต้องทำอะไร · แตะปุ่มไหน · ใช้เครื่องมืออะไร" — ตอบได้จากแถบภารกิจหรือไม่ · หาป้าศรี/ลุงคำเจอจากลูกศรขอบจอหรือไม่ · ตอนวัดระยะ บอกได้ไหมว่าวัดจากจุดใดถึงจุดใด
20. (v0.19) จอเล็กมาก (iPhone SE แนวนอน): แถบภารกิจไม่บังตัวผู้เล่น · แถบวัดระยะไม่บังแถบภารกิจ · ปุ่มลัดแตะง่าย

## วิธีทดสอบ: ภารกิจหลักต่อเนื่อง (เมนู · ฉากเชื่อมเรื่อง · แผนที่การเดินทาง)

1. เปิด http://localhost:5173 → เมนูหลัก (ครั้งแรกปุ่ม **เล่นต่อ** กดไม่ได้) · ปุ่ม **แผนที่การเดินทาง** แทน "เลือกด่าน"
2. **เริ่มเกมใหม่** → ฉากเปิดเรื่อง "บทที่ 1 · ตำบลสักงาม" (ครูเนมมอบภารกิจแผนที่ภูมิปัญญา) → `Space` อ่าน → **ออกเดินทาง** → ตำบลสักงาม
3. ระหว่างเล่น `Esc` → **แผนที่การเดินทาง**: การ์ดสักงาม "ภารกิจปัจจุบัน · มีบันทึกค้างอยู่" คลองน้ำไหล "เป้าหมายต่อไป"
   ไม่มีปุ่มเข้าด่านรายตำบล มีแค่ปุ่ม **เล่นต่อ: บทที่ 1** → กลับตำแหน่งและสถานะเดิม
4. จบบท 1 → หน้าสรุปผล → `Enter` → ฉากเชื่อมเรื่อง "บทที่ 2" ครูเนมพูดถึงรหัส "ลาย" และมอบภารกิจคลองน้ำไหล → ออกเดินทาง
5. ลองข้ามบท: เปิด `?level=level-3` หรือ `?level=level-4` หรือย้อนบท `?level=sakngam` / `?new=1` → ต้องถูกส่งไปแผนที่การเดินทางเสมอ
6. เมนูหลัก → **เล่นต่อ** → ต้องกลับไปบทปัจจุบัน ตำแหน่งเดิม · ถ้าเพิ่งจบบท (ยังไม่เริ่มบทใหม่) จะเปิดฉากเชื่อมเรื่องของบทถัดไป
7. ทำต่อจนจบบท 4 → ฉากเชื่อมเรื่อง "บทที่ 5" → ปริศนาสุดท้าย → ฉากจบ (ดูหัวข้อถัดไป)
8. **เริ่มเกมใหม่** เมื่อมีบันทึก ต้องมีหน้าต่างยืนยันก่อนลบความคืบหน้า

ทางลัดสำหรับนักพัฒนา: `?level=<id>` เข้าด่านแบบเล่นต่อ และ `?new=1` เริ่มบทที่ 1 ใหม่ — **ใช้ได้เฉพาะบทปัจจุบัน**
(บทอื่นถูกส่งไปแผนที่การเดินทาง)

## วิธีทดสอบ: ด่าน 2 (คลองน้ำไหล) ครบ 6 ฉาก

1. เข้าบทที่ 2 ผ่านภารกิจหลักเท่านั้น: จบบท 1 → `Enter` ที่หน้าสรุปผล → ฉากเชื่อมเรื่อง → ออกเดินทาง
2. **ฉาก 1:** คุยกับ **ครูเนม** → ได้แผนที่ฐาน A และ B → กด `M` แล้ว `Tab` ดูให้ครบทั้งสองฉบับ (ดูกล่องสัญลักษณ์ด้านขวา)
3. **ฉาก 2:** คุยกับ **ยายหอม** (หมู่บ้าน) และ **ลุงเพชร** (ไร่) แล้วเดินไปให้ถึง **สะพาน** และ **ฝาย (จุด B)**
4. **ฉาก 3:** คุยกับ **ป้าจันทร์** ที่ศาลาจัดการน้ำ → ได้ความสูง A 145 / B 130 / C 115 ม. → ตอบทิศน้ำไหล
   (ลองตอบ "C → B → A ไปทางใต้" ก่อน จะได้คำใบ้)
5. **ฉาก 4:** กด `C` เปิดหน้าเปรียบเทียบ — ลองกด 1 ก่อนไปไหน (ต้องขึ้นว่ายังตัดสินไม่ได้) → เดินไปดู **หินใหญ่สามก้อน** และ **จุด C**
   → กด `C` แล้วเลือกฉบับ (ลองเลือกผิดก่อนเพื่อดูคำอธิบาย)
6. **ฉาก 5:** เดินไปจุดที่ตรงกับหลักฐาน กด `E` สำรวจ → `M` → `Space` ปักหมุด → เลือกประเภทสถานที่
7. **ฉาก 6:** ครูเนมสรุป → หน้าสรุปผล รหัสลับ "ลาย · น้ำ · ? · ?" → `Enter` → ฉากเชื่อมเรื่องบทที่ 3
8. ไม่บังคับ: ภารกิจรองอ่านป้ายวัดระดับครบ 3 จุด · ภารกิจปริศนาไหโบราณ (ฟังยายหอมหลังฉาก 3 แล้วหายอดเนินด้วยเส้นชั้นความสูง)

## วิธีทดสอบ: บท 3 "ปริศนาเมืองโบราณใต้ผืนดิน" (v0.20 แบบ 2 เกณฑ์)

1. **ฉาก 1:** ครูเนม → เกณฑ์ "ระดับความสูง 50 + ระยะจากแหล่งน้ำ 50 · ผ่านเมื่อมากกว่า 70" + แผนที่ภูมิประเทศ (ครูเนมบอกว่าเป็นสถานการณ์จำลอง)
2. **ฉาก 2:** ลุงสอน (ลองตอบ "118 ม." ก่อน ดูคำใบ้ — ต้องลบความสูงลำน้ำ) → ป้าจันทร์ที่ศาลาประชาคม
3. **ฉาก 3:** ปุ่มลัด "🔍 วิเคราะห์พื้นที่" → แตะแผนที่ (มือถือแตะ "ย่อ" เพื่อเห็นทั้งแผนที่) → วงกลมเหลือง "รัศมี 40 ม." → แตะที่อื่นเพื่อเลือกใหม่ → ลอง "ปิดแผนที่" (ต้องยังไม่นับว่าวิเคราะห์) → เปิดใหม่ เลือก แล้ว "วิเคราะห์พื้นที่นี้" (คอมพิวเตอร์: คลิก + Space)
4. ตรวจผลใต้แผนที่: พื้นที่ที่เลือก (E/N) · ระดับความสูง … ม. (สูง/ต่ำกว่าลำน้ำ … ม.) …/50 · ระยะจากแหล่งน้ำ ~… ม. …/50 · คะแนนรวม …/100 · ผลการวิเคราะห์ — ต้องไม่มีคำว่าความลาดชัน
5. **ไม่ผ่าน:** ลองเลือกที่ราบฝั่งตะวันตกของลำห้วย (ต่ำกว่าลำน้ำ) → "ไม่ผ่าน — ทบทวน ระดับความสูง · กลับไปพบครูเนม" → เลือกใหม่ไม่ได้จนกว่าคุยกับครูเนม → ครูเนมอธิบายเฉพาะเรื่องที่พลาด → เลือกใหม่ (ลองหาที่ได้ 70 พอดี — ต้องไม่ผ่าน)
6. **ผ่าน:** "ผ่าน ✓ นำพื้นที่นี้ไปสำรวจต่อได้ (ยังไม่ใช่การพบเมืองโบราณ)" → วงสีเขียว
7. **ฉาก 5–6:** พี่เขียว → เดินไปวงสีเขียว → "ตรวจสอบ" (ตรวจตำแหน่ง · วัดจริง · พบหลักฐานจำลอง) → พี่เขียวยืนยัน → ครูเนมสรุป → รหัส "พิกัด" → บทที่ 4 ปลดล็อก
8. ออกกลางฉาก 4/5 แล้วเล่นต่อ: ประวัติการเลือกและพื้นที่ที่เลือกยังอยู่ · บันทึกกลางบทที่ 3 รุ่นเก่าถูกรีเซ็ตเฉพาะบทที่ 3 พร้อมข้อความแจ้ง

## วิธีทดสอบ: บท 4 (คลองลานพัฒนา) ครบ 7 ฉาก และบท 5 ปริศนาสุดท้าย

1. ฉาก 1–3: ครูเนม (มาตราส่วน) → หมุด RP-1/2/3 + พี่ต้นกล้า (ระยะเส้นตรง vs ตามถนน) → ป้าบัวลอย (ทิศน้ำไหล + สัญลักษณ์)
2. **ฉาก 4:** ลุงจำรัสในชุมชน → คำนวณ N = N ของ RP-2 + 250 (ลองตอบ "ลบ" ก่อน) → อ่านค่า E ที่เลือน `5,?40`
3. **ฉาก 5:** เดินไปจุด A, B, C กด `E` สำรวจ → กด `C` กระดานวิเคราะห์หลักฐาน → กดเลขเลือก → `Enter` ยืนยัน
   (ลองเลือก A ก่อน: ตรงพิกัดและภูมิประเทศแต่ทิศจากสะพานผิด) · ลอง `Esc` ออกกลางฉากแล้วเล่นต่อ
4. **ฉาก 6:** ที่จุดที่วิเคราะห์ได้ ลอง `M` ปักทันที (ต้องขึ้นว่าขาดบันทึกข้อมูลภูมิปัญญา) → กด `E` ตรวจยืนยัน 3 ข้อ → `M` → `Space` → เลือกประเภท
5. **ฉาก 7:** ครูเนมสรุป → รหัสชิ้นที่ 4 → หน้าสรุปผล → `Enter` → ฉากเชื่อมเรื่องบทที่ 5
6. **บท 5:** คุยครูเนม → ป้ายจัดแสดง 4 ป้าย (ตอบจากหลักฐานของแต่ละตำบล) → ตู้แผนที่ (ใส่รหัสตามทักษะของแต่ละช่อง)
   → คำถามสรุปความรู้กับครูเนม → ฉากจบ → **สรุปการเดินทาง** (แผนที่ภูมิปัญญา 4 ตำบล + ผลการเรียนรู้)
7. หลังจบเกม: แผนที่การเดินทางขึ้น "สำรวจครบทั้ง 4 ตำบล ✓" · `?level=<id>` ใด ๆ เข้าเล่นซ้ำไม่ได้ · เมนู "เล่นต่อ" → สรุปการเดินทาง

## วิธีทดสอบ: เล่นด่าน 1 ตั้งแต่ต้นจนจบ

1. `npm run dev` แล้วเปิด http://localhost:5173/?new=1 (หรือเข้าจากเมนู → เริ่มเกมใหม่)
2. **ช่วงที่ 1 (รับภารกิจ):** ทำตามแถบภารกิจ — ครูเนม (มี ! และลูกศรขอบจอ) → ศาลาชุมชน (ผู้ใหญ่บ้านทักเอง) → ตอบคำถาม (ลองผิดก่อนเพื่อดูคำใบ้)
3. **ช่วงที่ 2 ขั้น 1–4:** ลูกศรสีเหลืองชี้ไป **ป้าศรี** (กดปุ่มลัด "🗺️ ดูบนแผนที่" ดูจุด "! ป้าศรี (เป้าหมาย)") → เดินถึง → "✋ คุยกับป้าศรี" บนแถบภารกิจ → แล้ว **ลุงคำ**
4. **ขั้น 5–6:** ปุ่มลัด "📒 เปิดสมุด หน้าเบาะแส" (เบาะแสใหม่มี ★) → ปิดสมุด → ปุ่มลัด "📏 วัดจากศาลา" → เส้นประจากศาลามาถึงตัวเรา · แถบวัดระยะ "ระยะจากศาลาชุมชน: … เมตร" เปลี่ยนเมื่อเดิน
5. **ขั้น 7–8:** ปุ่ม 🔍 (หรือ `C`) เปิดกระดานวิเคราะห์เส้นทาง → เลือกผิดก่อน (บอกหลักฐานที่ขัดแย้ง) → เลือกเส้นทางที่ตรงกับข้อมูล
6. **ขั้น 9–11:** ออกสำรวจเอง (ไม่มีลูกศรนำทาง) — ที่บ้านผ้าปัก แถบวัดระยะควรแสดงประมาณ 400 ม. (= 4 ซม. ตามเบาะแส) → คุยกับ **ป้านวล**
7. **ขั้น 12:** ปุ่มลัด "📍 ไปปักหมุด" → เลื่อนหมุด → ปักหมุด → เลือกประเภทภูมิปัญญา
8. **ขั้น 13:** ปุ่มลัดอ่านปริศนา → "📏 วัดจากบ้านไหนเจียว" → เดินตามทิศจนระยะ ≈ 300 ม. → `E`/✋ สำรวจ → ครูเนมมอบรหัส "ลาย" → หน้าสรุปผล
9. **บันทึกความคืบหน้า:** เล่นถึงกลางด่าน รอ 5 วินาที แล้วรีโหลดหน้า → ต้องเล่นต่อจากจุดเดิม
   เปิด http://localhost:5173/?new=1 เพื่อเริ่มใหม่ ข้อมูลอยู่ใน DevTools → Application → Local Storage → `khlonglan-geo-rpg:progress`

ทดสอบระบบเดิม: เดินชนรั้ว/ต้นไม้/ลำห้วยต้องผ่านไม่ได้ และระยะเดินสะสม (สมุด หน้าหลักฐาน) ต้องไม่เพิ่มขณะดันกำแพง, กด `G` นับช่องเทียบแถบมาตราส่วน 50 ม.
