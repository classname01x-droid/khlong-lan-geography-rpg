# Geography Mystery RPG: ปริศนาลับแห่งคลองลาน

เกมสืบสวนภูมิศาสตร์ 2D Pixel Art (Top-down) สำหรับนักเรียน ใช้พื้นที่ 4 ตำบลในอำเภอคลองลานเป็นฉาก
ผู้เล่นใช้ **ทิศทาง มาตราส่วน ระยะทาง และจุดสังเกต** เพื่อแก้ปริศนา และรวบรวมรหัสลับจากทั้ง 4 ตำบล

> สถานะ: **v0.13** — **เกมผจญภัยแบบภารกิจหลักต่อเนื่อง เล่นได้ตั้งแต่เริ่มเรื่องจนจบเกม**: นักสำรวจของครูเนมเดินทาง
> บทที่ 1 สักงาม → 2 คลองน้ำไหล → 3 โป่งน้ำร้อน → 4 คลองลานพัฒนา → 5 ปริศนาสุดท้าย (โรงเรียนบ้านสักงาม) → ฉากจบและสรุปผลการเรียนรู้
> ภาพทั้งหมดเป็น placeholder ที่สร้างด้วยโค้ด · ผังแผนที่และเนื้อหาภูมิปัญญายังเป็นข้อมูลสมมติที่ต้องตรวจกับชุมชน
> **เล่นบนมือถือได้ (Mobile-First):** จอยสติก 8 ทิศ ปุ่มสัมผัสตามสถานการณ์ แถบติดตามภารกิจมุมขวาบน และคำใบ้แบบเป็นขั้น — คีย์บอร์ดยังใช้ได้ครบ
> **v0.13 อ่านง่ายบนโทรศัพท์:** สมุดภาคสนาม กระดานวิเคราะห์ หลักฐานเปรียบเทียบแผนที่ หน้าสรุป และเมนูหยุดเกม เป็นหน้าอ่านตัวอักษรใหญ่ (แท็บ + เลื่อนอ่าน) · แผนที่ขยาย/ลากเลื่อนได้ พร้อมแผงคำอธิบายสัญลักษณ์

## เริ่มต้นใช้งาน

ต้องใช้ Node.js 22.12 ขึ้นไป

```bash
npm install
npm run dev        # เปิด http://localhost:5173
```

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `npm run dev` | รันเกมโหมดพัฒนา (แก้โค้ดแล้วรีโหลดอัตโนมัติ) |
| `npm test` | รัน unit test (มาตราส่วน ระยะทาง ทิศ หมอก เส้นทาง ภารกิจ เบาะแส ปักหมุด จบด่าน บันทึกความคืบหน้า ปุ่มสัมผัส แถบภารกิจ คำใบ้) |
| `npm run typecheck` | ตรวจ TypeScript |
| `npm run build` | ตรวจ type แล้ว build ไปที่ `dist/` |
| `npm run preview` | เปิดไฟล์ที่ build แล้ว |

## การควบคุม

| ปุ่ม | การทำงาน |
|---|---|
| `W A S D` / ปุ่มลูกศร | เดิน (เดินทแยงได้) |
| `E` / `Space` / `Enter` | คุยกับ NPC ที่อยู่ใกล้ / ตรวจค้นจุดที่ยืนอยู่ / ไปบทพูดถัดไป |
| `1` `2` `3` | ตอบคำถามเลือกตอบ / เลือกเส้นทางในสมุด / เลือกประเภทภูมิปัญญาตอนปักหมุด |
| `R` | เริ่มวัดระยะใหม่จากจุดที่ยืน |
| `G` | เปิด/ปิดเส้นตาราง (เส้นบาง = 10 ม., เส้นหนา = 100 ม.) |
| `N` | เปิด/ปิดสมุดภาคสนาม: ภารกิจ / เบาะแส / วิเคราะห์เส้นทาง / หลักฐาน (`◀ ▶` หรือ `A` `D` เปลี่ยนหน้า) |
| `Delete` ×2 | (ในหน้า หลักฐาน/ข้อความ) เริ่มด่านนี้ใหม่ |
| `Esc` | ในด่าน: เมนูหยุดเกม (แผนที่การเดินทาง / เมนูหลัก) · หน้าสรุปผล: แผนที่การเดินทาง (`Enter` = รับภารกิจบทถัดไป) |
| `Tab` (ในแผนที่) | สลับแผนที่สำรวจ ↔ แผนที่ฐานแต่ละฉบับ (ด่าน 2) |
| `C` | หน้าเปรียบเทียบแผนที่ฐาน (ด่าน 2) — กด `1`/`2` เลือกฉบับที่ถูก |
| `↑ ↓` + `Enter` / เมาส์ | เลือกในเมนูหลัก แผนที่การเดินทาง ฉากเชื่อมเรื่อง และหน้าต่างยืนยัน |
| `M` / `Esc` | เปิด/ปิดแผนที่สำรวจ (มาตราส่วน 1:10,000) — ในโหมดปักหมุดใช้ `WASD`/ลูกศรเลื่อนหมุด และ `Space` ปัก |

ถือโทรศัพท์**แนวนอน** (ถ้าถือแนวตั้งเกมจะหยุดชั่วคราวและบอกให้หมุนจอ — ความคืบหน้าไม่หาย)

| ปุ่มใหญ่สีเหลือง ✋ (เช่น "คุย" / "สำรวจ" / "ตรวจสอบ") | โต้ตอบกับสิ่งที่อยู่ใกล้ที่สุด — กดไม่ได้เมื่อไม่มีอะไรในระยะ | `E` |
| 🗺️ แผนที่ · 📒 สมุด · 📏 วัดระยะ · 🔍 วิเคราะห์/เทียบแผนที่ · # ตาราง · ☰ เมนู | ตามชื่อปุ่ม (ปุ่มวิเคราะห์มีเฉพาะด่านที่ใช้) | `M` `N` `R` `C` `G` `Esc` |
| แตะกล่องบทสนทนา | อ่านบรรทัดถัดไป | `Space` |
| ปุ่มคำตอบขนาดใหญ่ | ตอบคำถาม / เลือกเส้นทาง / เลือกประเภทภูมิปัญญา / เลือกจุด A B C | `1` `2` `3` |
| ในแผนที่: แตะช่องบนแผนที่ แล้ว 📍 ปักหมุดตรงนี้ · 🔁 สลับแผ่น | ปักหมุด / สลับแผนที่ฐาน | ลูกศร + `Space` · `Tab` |
| ในแผนที่: ＋ ขยาย / － ย่อ · ลากนิ้วเพื่อเลื่อน · 📖 สัญลักษณ์ | อ่านชื่อสถานที่บนจอเล็ก (มาตราส่วนและพิกัดเดิม — แถบ 100 ม. ยาวตามการขยาย) | — |
| สมุด / กระดานวิเคราะห์ / เปรียบเทียบแผนที่: แตะแท็บด้านบน · ลากนิ้วขึ้นลงเพื่ออ่านต่อ | หน้าอ่านตัวอักษรใหญ่ (ไม่ย่อทั้งหน้าต่าง) | `◀ ▶` |
| ☰ เมนู → ปุ่มใหญ่ เล่นต่อ / แผนที่การเดินทาง / กลับเมนูหลัก | เมนูหยุดเกม | `Esc` แล้ว `1` `3` `4` |
| แถบภารกิจมุมขวาบน: ย่อ · รายละเอียด · 💡 ขอคำแนะนำ | ดูเป้าหมายและความคืบหน้า / ขอคำใบ้ขั้นถัดไป | — |

เครื่องที่ตรวจพบจอสัมผัสจะแสดงปุ่มอัตโนมัติ · บังคับได้ด้วย `?touch=1` (แสดงปุ่มบนคอมพิวเตอร์) หรือ `?touch=0` (ซ่อนปุ่ม)

## วิธีทดสอบ: เล่นบนมือถือ (v0.12–v0.13)

ทดสอบบนคอมพิวเตอร์: Chrome DevTools → Toggle device toolbar → เลือกโทรศัพท์ → หมุนเป็นแนวนอน → รีโหลด (ปุ่มจะขึ้นเมื่อมีจอสัมผัส)

ทดสอบบนโทรศัพท์จริง: `npm run build` แล้ว deploy โฟลเดอร์ `dist/` (เช่น Vercel/Netlify) หรือ `npm run dev -- --host` แล้วเปิดจาก IP ของเครื่องในวง Wi-Fi เดียวกัน

สิ่งที่ต้องตรวจด้วยมือบนเครื่องจริง (ยังไม่ได้ทดสอบบนโทรศัพท์จริง — ทดสอบอัตโนมัติด้วยการจำลองจอสัมผัสเท่านั้น):
1. iPhone (Safari) และ Android (Chrome) แนวนอน: จอยสติกเดินได้ 8 ทิศ ยกนิ้วแล้วหยุดทันที · เดินพร้อมกดปุ่มอื่นได้ (สองนิ้ว)
2. รุ่นที่มีรอยบาก/Dynamic Island: ปุ่มและภาพเกมไม่ถูกรอยบากบัง ทั้งหมุนซ้ายและหมุนขวา
3. แตะสองครั้งเร็ว ๆ / บีบนิ้ว: หน้าเว็บต้องไม่ซูมหรือเลื่อน · ปุ่มเดียวกันแตะครั้งเดียวทำงานครั้งเดียว
4. หมุนเป็นแนวตั้งระหว่างเล่น → ขึ้นหน้า "กรุณาหมุนโทรศัพท์" → หมุนกลับ → อยู่ที่เดิม
5. สลับแอป/ล็อกจอระหว่างกดจอยสติก → กลับมาแล้วตัวละครต้องไม่เดินเอง · ปิดแท็บแล้วเปิดใหม่ → เล่นต่อจากเดิม
6. อ่านเบาะแสในสมุด กระดานวิเคราะห์ และชื่อสถานที่บนแผนที่ (ระดับขยายเริ่มต้น) บนจอ 5–6 นิ้วได้สบายตาหรือไม่ · ลากเลื่อนอ่านในหน้าอ่านลื่นหรือไม่ (iOS Safari)
7. แผนที่: ลากเลื่อนแล้วหมุดไม่ย้ายเอง · แตะช่องแล้วหมุดไปถูกช่อง (ทุกระดับขยาย) · แผงสัญลักษณ์ตรงกับสัญลักษณ์บนแผนที่
8. ความลื่นไหล (FPS) และความร้อนของเครื่องเมื่อเล่นนาน 15 นาทีขึ้นไป · แบตเตอรี่/ประหยัดพลังงาน (Low Power Mode)
9. ขนาดตัวอักษรของระบบ (Dynamic Type / ขนาดตัวอักษร Android) และโหมดมืด ไม่ทำให้ปุ่มหรือหน้าอ่านล้นจอ

## วิธีทดสอบ: ภารกิจหลักต่อเนื่อง (เมนู · ฉากเชื่อมเรื่อง · แผนที่การเดินทาง)

1. เปิด http://localhost:5173 → เมนูหลัก (ครั้งแรกปุ่ม **เล่นต่อ** กดไม่ได้) · ปุ่ม **แผนที่การเดินทาง** แทน "เลือกด่าน"
2. **เริ่มเกมใหม่** → ฉากเปิดเรื่อง "บทที่ 1 · ตำบลสักงาม" (ครูเนมมอบภารกิจแผนที่ภูมิปัญญา) → `Space` อ่าน → **ออกเดินทาง** → ตำบลสักงาม
3. ระหว่างเล่น `Esc` → **แผนที่การเดินทาง**: การ์ดสักงาม "ภารกิจปัจจุบัน · มีบันทึกค้างอยู่" คลองน้ำไหล "เป้าหมายต่อไป"
   ไม่มีปุ่มเข้าด่านรายตำบล มีแค่ปุ่ม **เล่นต่อ: บทที่ 1** → กลับตำแหน่งและสถานะเดิม
4. จบบท 1 → หน้าสรุปผล → `Enter` → ฉากเชื่อมเรื่อง "บทที่ 2" ครูเนมพูดถึงรหัส "ลาย" และมอบภารกิจคลองน้ำไหล → ออกเดินทาง
5. ลองข้ามบท: เปิด `?level=level-3` หรือ `?level=level-4` หรือย้อนบท `?level=sakngam` / `?new=1` → ต้องถูกส่งไปแผนที่การเดินทางเสมอ
6. เมนูหลัก → **เล่นต่อ** → ต้องกลับไปบทปัจจุบัน ตำแหน่งเดิม · ถ้าเพิ่งจบบท (ยังไม่เริ่มบทใหม่) จะเปิดฉากเชื่อมเรื่องของบทถัดไป
7. ทำต่อจนจบบท 4 → ฉากเชื่อมเรื่อง "บทที่ 5" → ปริศนาสุดท้าย → ฉากจบ (ดูหัวข้อถัดไป)
8. **เริ่มเกมใหม่** เมื่อมีบันทึก ต้องมีหน้าต่างยืนยันก่อนลบความคืบหน้า

ทางลัดสำหรับนักพัฒนา: `?level=<id>` เข้าด่านแบบเล่นต่อ และ `?new=1` เริ่มบทที่ 1 ใหม่ — **ใช้ได้เฉพาะบทปัจจุบัน**
(บทอื่นถูกส่งไปแผนที่การเดินทาง)

## วิธีทดสอบ: ด่าน 2 (คลองน้ำไหล) ครบ 6 ฉาก

1. เข้าบทที่ 2 ผ่านภารกิจหลักเท่านั้น: จบบท 1 → `Enter` ที่หน้าสรุปผล → ฉากเชื่อมเรื่อง → ออกเดินทาง
2. **ฉาก 1:** คุยกับ **ครูเนม** → ได้แผนที่ฐาน A และ B → กด `M` แล้ว `Tab` ดูให้ครบทั้งสองฉบับ (ดูกล่องสัญลักษณ์ด้านขวา)
3. **ฉาก 2:** คุยกับ **ยายหอม** (หมู่บ้าน) และ **ลุงเพชร** (ไร่) แล้วเดินไปให้ถึง **สะพาน** และ **ฝาย (จุด B)**
4. **ฉาก 3:** คุยกับ **ป้าจันทร์** ที่ศาลาจัดการน้ำ → ได้ความสูง A 145 / B 130 / C 115 ม. → ตอบทิศน้ำไหล
   (ลองตอบ "C → B → A ไปทางใต้" ก่อน จะได้คำใบ้)
5. **ฉาก 4:** กด `C` เปิดหน้าเปรียบเทียบ — ลองกด 1 ก่อนไปไหน (ต้องขึ้นว่ายังตัดสินไม่ได้) → เดินไปดู **หินใหญ่สามก้อน** และ **จุด C**
   → กด `C` แล้วเลือกฉบับ (ลองเลือกผิดก่อนเพื่อดูคำอธิบาย)
6. **ฉาก 5:** เดินไปจุดที่ตรงกับหลักฐาน กด `E` สำรวจ → `M` → `Space` ปักหมุด → เลือกประเภทสถานที่
7. **ฉาก 6:** ครูเนมสรุป → หน้าสรุปผล รหัสลับ "ลาย · น้ำ · ? · ?" → `Enter` → ฉากเชื่อมเรื่องบทที่ 3
8. ไม่บังคับ: ภารกิจรองอ่านป้ายวัดระดับครบ 3 จุด · ภารกิจปริศนาไหโบราณ (ฟังยายหอมหลังฉาก 3 แล้วหายอดเนินด้วยเส้นชั้นความสูง)

## วิธีทดสอบ: ด่าน 3 (โป่งน้ำร้อน) ครบ 6 ฉาก

1. เข้าบทที่ 3 ผ่านภารกิจหลักเท่านั้น: จบบท 2 → ฉากเชื่อมเรื่อง (รหัส "น้ำ") → ออกเดินทาง
2. ดู **พิกัดกริด** ที่มุมซ้ายบน: เดินขึ้น (เหนือ) ค่า N ต้องเพิ่ม · เดินไปขวา (ตะวันออก) ค่า E ต้องเพิ่ม · ทุก 1 ช่อง = 10 ม.
3. **ฉาก 1:** คุยกับ **ครูเนม** → แผนที่กริด + บันทึกสำรวจเก่า → ตอบพิกัดเสาธง (ลองข้อ 1 ที่นับ N จากขอบบน จะได้คำใบ้)
4. **ฉาก 2:** อ่านหมุดอ้างอิง **RP-1, RP-2, RP-3** (กด `E` ที่หมุด) และคุยกับ **ลุงสอน**
5. **ฉาก 3:** คุยกับ **ป้าเรือน** ที่ศาลาประชาคม → เบาะแสบันทึกผิด/ทิศ-ระยะจาก RP-2/ไอน้ำ-หินปูน → ตอบคำถาม N เพิ่มไปเหนือ
6. **ฉาก 4:** เดินไปสำรวจจุด A, B, C (กด `E`) → กด `C` เปิด **กระดานวิเคราะห์พิกัด** → กดเลข 1–3 เลือก (ยังไม่บอกผล) → `Enter` ยืนยัน
   (ลองเลือกจุด A ก่อน — ตรงกับตัวเลขในบันทึกถ้าอ่านตามที่เขียน — จะเห็นหลักฐานที่ขัดและคำใบ้)
7. **ฉาก 5:** ลองเปิด `M` ปักหมุดทันทีที่จุด → ต้องขึ้นว่าขาด "รายงานยืนยันภาคสนาม" → กด `E` ที่บ่อ ดูผลตรวจ 3 ข้อ
   → `M` → `Space` → เลือกประเภทสถานที่ (ลองเลือกผิดก่อน)
8. **ฉาก 6:** ครูเนมสรุปผ่านสมุด → หน้าสรุปผล รหัสลับ "ลาย · น้ำ · พิกัด · ?" → `Enter` → ฉากเชื่อมเรื่องบทที่ 4
9. ลองออกกลางฉาก 4 หรือ 5 (`Esc` → แผนที่การเดินทาง) แล้วกลับมาเล่นต่อ: จำนวนครั้งที่ตอบผิด ประวัติบนกระดาน และหลักฐานต้องอยู่ครบ
10. ไม่บังคับ: ภารกิจรอง "เดินตามพิกัด" (พี่เขียว) · ภารกิจปริศนา "หมุดสำรวจที่หายไป" (คุยลุงสอนอีกครั้งหลังฉาก 3)

## วิธีทดสอบ: บท 4 (คลองลานพัฒนา) ครบ 7 ฉาก และบท 5 ปริศนาสุดท้าย

1. ฉาก 1–3: ครูเนม (มาตราส่วน) → หมุด RP-1/2/3 + พี่ต้นกล้า (ระยะเส้นตรง vs ตามถนน) → ป้าบัวลอย (ทิศน้ำไหล + สัญลักษณ์)
2. **ฉาก 4:** ลุงจำรัสในชุมชน → คำนวณ N = N ของ RP-2 + 250 (ลองตอบ "ลบ" ก่อน) → อ่านค่า E ที่เลือน `5,?40`
3. **ฉาก 5:** เดินไปจุด A, B, C กด `E` สำรวจ → กด `C` กระดานวิเคราะห์หลักฐาน → กดเลขเลือก → `Enter` ยืนยัน
   (ลองเลือก A ก่อน: ตรงพิกัดและภูมิประเทศแต่ทิศจากสะพานผิด) · ลอง `Esc` ออกกลางฉากแล้วเล่นต่อ
4. **ฉาก 6:** ที่จุดที่วิเคราะห์ได้ ลอง `M` ปักทันที (ต้องขึ้นว่าขาดบันทึกข้อมูลภูมิปัญญา) → กด `E` ตรวจยืนยัน 3 ข้อ → `M` → `Space` → เลือกประเภท
5. **ฉาก 7:** ครูเนมสรุป → รหัสชิ้นที่ 4 → หน้าสรุปผล → `Enter` → ฉากเชื่อมเรื่องบทที่ 5
6. **บท 5:** คุยครูเนม → ป้ายจัดแสดง 4 ป้าย (ตอบจากหลักฐานของแต่ละตำบล) → ตู้แผนที่ (ใส่รหัสตามทักษะของแต่ละช่อง)
   → คำถามสรุปความรู้กับครูเนม → ฉากจบ → **สรุปการเดินทาง** (แผนที่ภูมิปัญญา 4 ตำบล + ผลการเรียนรู้)
7. หลังจบเกม: แผนที่การเดินทางขึ้น "สำรวจครบทั้ง 4 ตำบล ✓" · `?level=<id>` ใด ๆ เข้าเล่นซ้ำไม่ได้ · เมนู "เล่นต่อ" → สรุปการเดินทาง

## วิธีทดสอบ: เล่นด่าน 1 ตั้งแต่ต้นจนจบ

1. `npm run dev` แล้วเปิด http://localhost:5173/?new=1 (หรือเข้าจากเมนู → เริ่มเกมใหม่)
2. **ฉาก 1:** เดินไปหา **ครูเนม** (มี ! เหนือหัว) กด `E` → ได้เบาะแสทิศและระยะไปศาลาชุมชน (กด `N` ดูในสมุด)
3. **ฉาก 2:** กด `R` เริ่มวัดระยะ เดินออกประตูโรงเรียน → ถนนหลัก → ข้ามสะพาน → ไปทางตะวันออก
   เมื่อถึงหน้าศาลา ผู้ใหญ่บ้านจะเริ่มคุยเอง (ระยะที่วัดได้จะมากกว่าระยะเส้นตรงที่ครูบอก)
4. **ฉาก 3:** ตอบปริศนาด้วย `1`–`3` — ลองตอบผิดก่อนเพื่อดูคำใบ้ แล้วตอบ "ผ้าปัก"
   → ได้เบาะแส **ทิศทาง** และ **ระยะทาง** (4 ซม. บนแผนที่ 1:10,000) → คำถามข้อ 2: 4 ซม. = กี่เมตร (ตอบ 400 ม.)
5. **ฉาก 4:** คุยกับ **ลุงคำ** ริมลำห้วยใกล้สะพานถนนหลัก (เบาะแส **จุดสังเกต**: สะพานไม้)
   และ **ป้าศรี** ที่ต้นสักใหญ่ (ทางแยก) ลองเดินสำรวจปลายทางแต่ละเส้น
   แล้วกด `N` → หน้า "วิเคราะห์เส้นทาง" → กด `1`/`2`/`3` เลือกเส้นทาง (เลือกผิดจะบอกว่าหลักฐานข้อไหนไม่ตรง)
6. **ฉาก 5:** เดินตามเส้นทางที่ถูก ข้ามสะพานไม้ ไปคุยกับ **ป้านวล** ช่างผ้าปักที่บ้านไหนเจียว → ได้หลักฐาน
7. **ฉาก 6:** กด `M` → เลื่อนหมุดไปที่บ้านไหนเจียว → `Space` → เลือกประเภทภูมิปัญญา
   → ครูเนมติดต่อผ่านสมุดภาคสนาม → หน้าสรุปผล (ระยะทาง เบาะแส ตอบผิด เวลา ทักษะ) และบันทึกการผ่านด่าน
8. **ภารกิจรอง/ปริศนา (ไม่บังคับ):** กด `N` หน้า "ภารกิจ" ดูสถานะ — ภารกิจปริศนาปลดล็อกหลังคุยกับป้านวล
   เบาะแสบอกให้เดินไปทางตะวันตก 3 ซม. บนแผนที่ (= 300 ม. = 30 ช่อง) แล้วกด `E` ตรวจค้นที่ต้นไม้ใหญ่
9. **บันทึกความคืบหน้า:** เล่นถึงกลางด่าน รอ 5 วินาที แล้วรีโหลดหน้า → ต้องเล่นต่อจากจุดเดิม
   เปิด http://localhost:5173/?new=1 เพื่อเริ่มใหม่ ข้อมูลอยู่ใน DevTools → Application → Local Storage → `khlonglan-geo-rpg:progress`

ทดสอบระบบเดิม: เดินชนรั้ว/ต้นไม้/ลำห้วยต้องผ่านไม่ได้ และ "ระยะทางรวม" ต้องไม่เพิ่มขณะดันกำแพง, กด `G` นับช่องเทียบแถบมาตราส่วน 50 ม.
